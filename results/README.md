# Experimental Results

This directory contains the reproducible experimental evidence generated by the uncertainty-aware surgical navigation research framework.

## Final Evidence

`final_evidence/` is the authoritative project-level evidence package.

It contains:

- `final_metrics.csv` - consolidated final metrics
- `final_results_report.md` - human-readable final experimental report
- `final_results_summary.json` - machine-readable final summary
- `reproducibility_manifest.json` - provenance and links to source experimental evidence

## Primary and Development Experiments

- `phase1_*` - fair-comparison protocol development, validation, held-out evaluation and supporting analyses
- `phase2/` - collision-aware planning benchmark
- `phase3/` - stereo uncertainty benchmark
- `phase4/` - segmentation and perception uncertainty experiments
- `phase5/` - registration and tracking experiments
- `phase6_*` - chance-constrained planning, closed-loop navigation and robustness stress testing
- `phase7_*` - autonomous runtime safety and safety-smoke experiments

## Three-Strategy Evidence

- `e4_100_trials/` - three-strategy statistical comparison
- `e5_robustness/` - robustness comparison
- `e6_mechanism/` - mechanism ablation
- `e7_uncertainty_stress/` - uncertainty-stress evaluation

These directories are referenced by the final evidence package and reproducibility manifest and should retain their existing paths.

## Supplementary Evidence

- `supplementary_efficiency/` - efficiency comparison
- `supplementary_illumination/` - illumination degradation analysis
- `supplementary_uncertainty_calibration/` - uncertainty calibration analysis

## Statistical Visualisation Evidence

- `day7_statistical_trials.csv` - trial-level statistical benchmark data
- `figures/` - figures generated from the Day 7 statistical results
- `active_perception_figures/` - active-perception analysis figures

## Reproducibility

Generated experimental evidence should not be manually modified. Results should be regenerated using the corresponding code under `src/simulation/`, the documented environment, deterministic seed policy and experiment configuration.

For the overall project methodology, see [`../docs/experimental_protocol.md`](../docs/experimental_protocol.md).
